# man
## DESCRIPTION
`muster fable` opens a Claude Code Fable participant for a named window. The
session works from `~/pane/<slug>` and participates in Muster as
`<slug>-fable`.

`muster fable run` opens the participant in a persistent tmux popup. Muster
creates one session ID automatically, starts it with `Ping.`, and resumes it
after the process is restarted.
