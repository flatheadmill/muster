# man
## DESCRIPTION
`muster claude` opens a Claude Code participant for a named window. The session
works from `~/pane/<slug>` and participates in Muster as `<slug>-claude`.

`muster claude run` opens the participant in a persistent tmux popup. Muster
creates one session ID automatically, starts it with `Ping.`, and resumes it
after the process is restarted.
