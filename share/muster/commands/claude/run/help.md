# man
## DESCRIPTION
`muster claude run` opens a Claude Code participant in a full-screen tmux popup.
Muster creates the session ID automatically and uses `Ping.` to initialize the
conversation. Later process launches resume that ID. Closing the popup detaches
it; opening it again returns to the same process and conversation.
