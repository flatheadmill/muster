# desc
Create an OMP topic.
# opt help
Display help for `muster omp create`.
# opt slug
Set the window slug.
# opt topic
Set the new topic name.
# opt model
Set the stable model alias: `sol`, `opus`, or `fable`.
# man
## DESCRIPTION
Creates a topic directory and records its model alias. This command does not
start OMP or change the active topic.
