# man
## DESCRIPTION
`muster grok` associates one Grok Build session with a named window. The
session works from `~/pane/<slug>` and participates in Muster as `<slug>-grok`.

`muster grok run` reserves a session ID when needed and opens or resumes the
conversation in a persistent tmux popup. `muster grok create` remains available
to reserve the ID without starting Grok.
