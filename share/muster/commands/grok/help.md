# man
## DESCRIPTION
`muster grok` associates one explicit Grok Build session with a named window.
The session works from `~/pane/<slug>` and participates in Muster as
`<slug>-grok`.

`muster grok create` reserves a session ID without starting Grok. `muster grok
run` creates or resumes that conversation in a persistent tmux popup.
